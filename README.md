# F Klavye Atölyesi — öğrenci sürümü

F klavye yazma çalışmaları ve sınav simülasyonu. Tek sayfalık, sunucusuz uygulama (`index.html`).

- Çalışma kayıtları öğrencinin kendi tarayıcısında saklanır; sunucuya hiçbir veri gönderilmez.
- Fiziksel klavye gerektirir (bilgisayar); telefonda çalışmaz.
- Arama motorlarına kapalıdır (`noindex`, `robots.txt`).
